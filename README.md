# Flask Authentication System 

A Flask authentication application that demonstrates user registration, login, secure password hashing with Werkzeug, session management with Flask-Login, and user persistence using SQLite and SQLAlchemy.

## Project Overview

This project demonstrates a complete authentication workflow using Flask. Users can register, log in with securely hashed passwords, access protected routes, and log out. User credentials are stored in a SQLite database using SQLAlchemy.

## Features

- User registration
- User login and logout
- Secure password hashing with Werkzeug
- Protected routes with Flask-Login
- User data persistence using SQLite

## Technologies

- Python
- Flask
- Flask-Login
- SQLAlchemy
- SQLite
- Werkzeug Security


## Installation

1. Clone the repository

```bash
git clone https://github.com/gustavodev6331/login-auth.git
```
2. Install the dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python main.py
```

4. Open your browser and visit:

```bash
http://127.0.0.1:5000
```
